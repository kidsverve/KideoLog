# 🚀 Kids Computer & AI — Intermediate 3 Month Learning Journey

A practical, project-based **3-month intermediate technology curriculum for kids** who already understand basic computer usage.

This level moves beyond:

> "What is a computer?"

toward:

> **"How does it work, how can I program it, and how can I use AI to build something useful?"**

The program combines:

* 💻 Computer concepts
* 🧠 Computational thinking
* 🐍 Programming
* 🌐 Web concepts
* 📊 Data
* 🤖 Artificial Intelligence
* 💬 Generative AI
* 🔐 Responsible technology use
* 🚀 Project-based learning

---

# 🎯 Who Is This For?

This plan is suitable for children who already know how to:

* Use a computer independently
* Browse the internet
* Create and save files
* Use common applications
* Perform basic searches
* Understand basic programming/block coding concepts

They don't need to be expert programmers.

---

# 🗓️ Program Structure

**Duration:** 12 weeks

**Recommended:** 3–4 active days per week

**Session:** 45–60 minutes

**Break:** 3–4 days per week

The program intentionally avoids daily lessons.

```text
Learn
  ↓
Practice
  ↓
Build
  ↓
Fun Challenge
  ↓
BREAK
  ↓
Come Back
```

# 👨‍👩‍👧 Parent / Mentor Guide

At the intermediate level, resist solving problems immediately.

Instead of:

> "Here's the code."

Ask:

> "What do you think the computer is doing?"

Then:

> "Which part isn't behaving the way you expected?"

Then:

> "How could we test that?"

And finally:

> "Can you explain why your solution works?"

---

# 🤖 Rules for Using AI During the Course

AI should be treated as a **learning assistant**, not an answer machine.

### Good uses

✅ Explain a concept
✅ Give hints
✅ Suggest project ideas
✅ Help find bugs
✅ Provide examples
✅ Help brainstorm
✅ Ask questions back

### Avoid

❌ Copying an entire project without understanding it
❌ Assuming AI answers are always correct
❌ Sharing private information
❌ Using AI to avoid learning the underlying concept

A useful rule:

> **If AI writes it, you should be able to explain it.**

# ⭐ Core Philosophy

The purpose of this intermediate program isn't to turn a child into a professional programmer or AI engineer.

The goal is to develop a **builder's mindset**.

Instead of:

> "I don't know how this works."

encourage:

> **"I don't know yet. Let's investigate."**

Instead of:

> "The code doesn't work."

encourage:

> **"Good. We found something to debug."**

Instead of:

> "AI said it, so it must be true."

encourage:

> **"How can we verify it?"**

And instead of:

> "I can't build that."

encourage:

> **"What is the smallest version I could build first?"**
